# Как пополнять портфолио

Сайт: <https://varlamvolkov.github.io/varlam-portfolio/>

## Один общий каталог

Новые события, публикации, исследования, проекты и волонтёрские материалы добавляются в `portfolio-data.json` — это единый источник для главной страницы и тематических разделов. Запись автоматически появляется в подходящих местах по меткам `category`:

- `research` — исследования: главная, «Обо мне», «Исследования»;
- `volunteering` — главная, «Обо мне», «СМИ и выступления»;
- `awards` — главная, «Обо мне», конкурсы и публикации;
- `talks`, `press`, `media` — главная, «Обо мне», «СМИ и выступления»;
- `projects` — главная, «Обо мне», раздел проектов.

Общие записи и аудио/видеокаталог сортируются от новых к ранним. Если проект уже подробно описан отдельной историей на странице проектов, добавьте ему `"featuredProject": true`, чтобы не дублировать карточку в автоматическом списке.

### Шаблон новой публикации или события

Добавьте объект в массив `timeline` и поставьте запятую после предыдущей записи:

```json
{
  "sort": "2026-11",
  "year": "2026",
  "title": "Название события или публикации",
  "description": "Короткое описание без предположений и неподтверждённых деталей.",
  "category": ["press", "volunteering"],
  "source": "Название издания или организатора",
  "url": "https://example.org/source",
  "linkText": "Открыть первоисточник ↗"
}
```

`sort` задаёт порядок (`ГГГГ-ММ`); если известен только год, укажите `ГГГГ-01`. `year` — подпись на карточке. Для второй ссылки используйте `extraUrl` и `extraText`, для третьей — `thirdUrl` и `thirdText`. Чтобы показать фотографию, положите её в `assets/images/` и добавьте `"image": "assets/images/имя-файла.jpg"`.

### Научная публикация с копированием цитирования

Для каждого исследования укажите полный текст библиографической записи в `citation`. На странице появится кнопка, которая скопирует её в буфер обмена и покажет подтверждение.

```json
{
  "sort": "2026-11",
  "year": "2026",
  "title": "Название статьи",
  "description": "О чём работа.",
  "category": ["research"],
  "authors": "И. И. Автор.",
  "details": "Журнал. Год. Том, номер, страницы.",
  "url": "https://doi.org/…",
  "linkText": "Открыть публикацию ↗",
  "citation": "Автор И. И. Название статьи // Название журнала. Год. Том, номер, страницы. DOI: …"
}
```

### Аудиозапись или видеосюжет

Сначала загрузите файл в `assets/audio/` или `assets/video/`, затем добавьте запись в тот же массив `timeline`:

```json
{
  "sort": "2026-11",
  "year": "2026",
  "displayDate": "Ноябрь 2026",
  "title": "Название записи",
  "description": "Короткое описание.",
  "category": ["audio"],
  "type": "audio",
  "audio": "assets/audio/example.mp3",
  "source": "Волкосказ · выпуск 05"
}
```

Для аудио «Волкосказ» добавьте также `"projects"` в `category`, чтобы запись появилась в блоке журнала, отдельно от примеров дикторской озвучки. Для видео используйте `"category": ["media"]`, `"type": "video"`, `"video": "assets/video/example.mp4"`, `"source": "Название канала"`; официальный адрес добавляется через `url`. Для `.mov` можно указать `"sourceType": "video/quicktime"`.

### Социальная сеть или профиль

Добавьте одну строку в массив `profiles` в том же файле:

```json
{"title":"Название профиля","url":"https://example.org/profile","group":"Профили"}
```

Ссылка автоматически появится в «Обо мне».

## Сохранить изменения на GitHub

1. Скопируйте фотографии, аудио или видео в соответствующую папку репозитория.
2. Измените `portfolio-data.json` и сохраните файл.
3. В GitHub Desktop проверьте список изменённых файлов, введите краткое описание (например, «Добавить выступление») и нажмите **Commit to main**.
4. Нажмите **Push origin**. После публикации GitHub Pages обновится автоматически через несколько минут.

Публикуйте только материалы, которые можно показывать публично. Для крупных видео используйте внешнюю ссылку на общедоступный источник; сам ролик можно не загружать в GitHub.
