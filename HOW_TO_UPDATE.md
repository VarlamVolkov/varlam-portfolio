# Как обновлять сайт

Рабочий сайт: <https://varlamvolkov.github.io/varlam-portfolio/>

## Добавить аудиозапись

1. Подготовьте MP3 и назовите файл латиницей, например `volkoskaz-05.mp3`.
2. На GitHub откройте `assets/audio/`, нажмите **Add file → Upload files**, выберите MP3 и сохраните изменения коммитом в `main`.
3. Откройте `audio-library.json`, нажмите значок карандаша и добавьте объект в список `tracks`:

```json
{
  "title": "Название выпуска",
  "category": "Волкосказ",
  "date": "Ноябрь 2026",
  "description": "Короткое описание записи.",
  "src": "assets/audio/volkoskaz-05.mp3"
}
```

4. Нажмите **Commit changes**. Сохраните запятые между объектами JSON; после последнего объекта запятую не ставьте.

## Добавить видео или сюжет

1. Откройте `video-library.json` и нажмите карандаш.
2. Добавьте объект в список `videos`:

```json
{
  "title": "Название сюжета",
  "channel": "Телеканал или проект",
  "date": "Ноябрь 2026",
  "description": "Коротко о сюжете.",
  "url": "https://example.com/video"
}
```

3. В `url` вставьте полный адрес опубликованной страницы Google Sites или страницу общего доступа к видеофайлу Google Drive. Страница сюжета появится в разделе **СМИ → Видео и сюжеты** после сохранения.

Сайт публичный, поэтому используйте только материалы, которые можно показывать всем. Для видео из Drive откройте доступ «Все, у кого есть ссылка — Читатель» в настройках конкретного файла. Сайт показывает кнопку перехода к видео; исходный файл остаётся на Google Drive. Страница Google Sites должна быть опубликована для просмотра всем, кому предназначен портфолио-сайт.

Если вы хотите, чтобы сами аудиофайлы хранились в репозитории, загрузите их в `assets/audio/` и укажите этот путь в `src`. Для больших файлов используйте внешнюю ссылку: не загружайте файлы свыше лимита GitHub (100 МБ на один файл).

## Полезные правила

- Загружайте файлы в соответствующую папку, а не в корень репозитория.
- Не удаляйте фигурные скобки и кавычки в JSON.
- Имена файлов и пути должны совпадать по регистру букв.
- После коммита подождите несколько минут и обновите опубликованный сайт.
- Не публикуйте личные или неопубликованные материалы без необходимости.
