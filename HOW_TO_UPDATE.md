# Как пополнять одностраничное портфолио

Сайт: <https://varlamvolkov.github.io/varlam-portfolio/>

## Общий каталог материалов

Новые публикации, выступления, исследования, проекты, волонтёрские события и аудио добавляйте в массив `timeline` файла `portfolio-data.json`. Главная сама распределяет запись по разделам согласно `category`: `audio`, `projects`, `volunteering`, `awards`, `talks`, `press`, `media`, `research`. Ссылки на личные профили добавляются в массив `profiles`.

Одна запись может отображаться в нескольких подходящих разделах. Для материалов с несколькими датами задавайте `sort` в формате `ГГГГ-ММ-ДД`, чтобы порядок внутри месяца был точным; если день неизвестен — используйте `ГГГГ-ММ`. Записи показываются от новых к ранним.

### Публикация или событие

```json
{
  "sort": "2026-11-16",
  "year": "2026",
  "title": "Название события или публикации",
  "description": "Короткое описание от первого лица или нейтральное описание результата.",
  "category": ["press", "volunteering"],
  "source": "Издание или организатор",
  "url": "https://example.org/source",
  "linkText": "Открыть первоисточник ↗"
}
```

Для дополнительных источников используйте `extraUrl`/`extraText` и `thirdUrl`/`thirdText`. Изображения разместите в `assets/images/` и укажите путь через `image`.

### Научная публикация и копирование цитирования

Каждой статье задайте полный текст библиографической записи в `citation`. На странице появится поле-кнопка: при нажатии запись копируется в буфер обмена.

```json
{
  "sort": "2026-11",
  "year": "2026",
  "title": "Название статьи",
  "category": ["research"],
  "authors": "И. И. Автор.",
  "details": "Журнал. Год. Том, номер, страницы.",
  "url": "https://doi.org/…",
  "linkText": "Открыть публикацию ↗",
  "citation": "Автор И. И. Название статьи // Журнал. Год. Том, номер, страницы. DOI: …"
}
```

### Аудио и видео

Загрузите файл в `assets/audio/` или `assets/video/`, затем укажите путь в записи. Для аудио используйте `"type": "audio"` и `"audio": "assets/audio/example.mp3"`. Для выпусков «Волкосказа» укажите категории `["audio", "projects"]`, чтобы они не смешивались с примерами дикторской озвучки.

Для видео используйте `"type": "video"`, `"category": ["media"]` и `"video": "assets/video/example.mp4"`. Если есть публичная ссылка на первоисточник, добавьте `url`: сайт покажет ссылку вместо тяжёлого локального плеера. Локальные видео без внешнего источника открываются по запросу и не загружаются при обычном просмотре страницы.

### Социальные и профессиональные профили

Добавьте объект в `profiles`: `{ "title": "Название", "url": "https://example.org", "group": "Профили" }`.

## Сохранение изменений

1. Добавьте нужный медиафайл в `assets/`.
2. Обновите `portfolio-data.json`; текст и разметка секций главной редактируются в `index.html`.
3. Проверьте, что путь к файлу, дата, категория и ссылка корректны.
4. Зафиксируйте и отправьте изменения в ветку `main`.

Не загружайте тяжёлый ролик, если его можно посмотреть по доступной публичной ссылке.
