# Портфолио Варлама Волкова

Основной сайт: <https://varlamvolkov.github.io/varlam-portfolio/>.

Репозиторий содержит основное портфолио и отдельную посадочную страницу дикторского направления по адресу `voice.html` (на текущем домене — `/voice.html`). Страницы используют общую навигацию и данные, но для страницы дикторства предусмотрена отдельная визуальная тема.

## Как устроен проект

- `index.html` — главная: профиль, образование, опыт, проекты и интересы.
- `about.html` — расширенная биография, опыт и образование.
- `voice.html` — дикторское портфолио и заявка на озвучку.
- `portfolio-data.json` — единый источник данных для карточек, образования, навыков, аудио и сертификатов.
- `assets/js/main.js` — отображение данных, фильтрация по категориям и аудиослайдер.
- `assets/css/style.css` — общие страницы; `assets/css/voice-landing.css` — оформление дикторской страницы.
- `assets/images/`, `assets/audio/`, `assets/video/` — медиафайлы.

Подробная инструкция по добавлению материалов находится в [`HOW_TO_UPDATE.md`](HOW_TO_UPDATE.md).

## Публикация

GitHub Pages настроен на публикацию из ветки `main` и корневой папки репозитория. Отправка изменений в `main` обновляет основной сайт и страницу `voice.html`. Для отдельного домена `volkov.voice` потребуется отдельная настройка домена и хостинга; адрес текущего проекта при этом не меняется автоматически.
