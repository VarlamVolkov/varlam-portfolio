# Портфолио Варлама Волкова

Основной сайт: <https://varlamvolkov.github.io/varlam-portfolio/>. Дикторская страница: <https://varlamvoice.ru/>.

Репозиторий содержит основное портфолио и отдельную посадочную страницу дикторского направления. На домене `varlamvoice.ru` дикторская страница открывается в корне сайта; файл `voice.html` остается её исходником, а основное портфолио продолжает открываться на GitHub Pages.

## Как устроен проект

- `index.html` — главная: профиль, образование, опыт, проекты и интересы.
- `about.html` — расширенная биография, опыт и образование.
- `voice.html` — дикторское портфолио и заявка на озвучку.
- `portfolio-data.json` — единый источник данных для карточек, образования, навыков, аудио и сертификатов.
- `assets/js/main.js` — отображение данных, фильтрация по категориям и аудиослайдер.
- `assets/css/style.css` — общие страницы; `assets/css/voice-landing.css` — оформление дикторской страницы.
- `assets/images/`, `assets/audio/`, `assets/video/` — медиафайлы.

Подробная инструкция по добавлению материалов находится в [`HOW_TO_UPDATE.md`](HOW_TO_UPDATE.md).

## Публикация

GitHub Pages настроен на публикацию из ветки `main` и корневой папки репозитория. Отправка изменений в `main` обновляет основное портфолио и дикторскую страницу. В корне домена `varlamvoice.ru` главная страница загружает `voice.html`, тогда как адрес проекта `varlamvolkov.github.io/varlam-portfolio/` сохраняет основное портфолио.
