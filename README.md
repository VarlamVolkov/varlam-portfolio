# Сайт-портфолио Варлама Волкова

Статический сайт для публикации через GitHub Pages. Не требует WordPress, платных конструкторов или сборки.

## Состав
- `index.html` — главная
- `voice.html` — дикторское портфолио и аудиозаписи
- `media.html` — СМИ и выступления
- `science.html` — исследования и публикации
- `about.html` — обо мне
- `assets/` — стили, скрипт, изображения и аудиофайлы
- `audio-library.json` — список аудиозаписей для дальнейшего расширения

## Публикация на GitHub Pages
1. Создайте аккаунт на github.com и войдите.
2. Нажмите New repository. Название, например, `varlam-portfolio`.
3. Для простоты выберите Public.
4. Загрузите всё содержимое этой папки в корень репозитория (не саму папку целиком).
5. Откройте Settings → Pages.
6. В разделе Build and deployment выберите `Deploy from a branch`.
7. В Branch выберите `main`, папку `/ (root)`, нажмите Save.
8. Через несколько минут GitHub покажет адрес вида `https://ВАШ-ЛОГИН.github.io/varlam-portfolio/`.

## Как добавить аудио
На первом этапе аудиофайлы подключены напрямую в `voice.html`.
1. Подготовьте MP3, желательно 128–192 kbps.
2. Загрузите файл в `assets/audio/`.
3. Добавьте новый объект в массив `tracks` файла `audio-library.json` — укажите `title`, `category`, `date`, `description` и `src`.
4. Сохраните изменения в GitHub — карточка появится на странице «Диктор» автоматически.

Пример объекта:
```json
{
  "title": "Название записи",
  "category": "Рекламная озвучка",
  "date": "Ноябрь 2026",
  "description": "Короткое описание проекта.",
  "src": "assets/audio/nazvanie-zapisi.mp3"
}
```

## Важно
GitHub Pages бесплатен для публичных репозиториев, но это статический хостинг: здесь нет панели администратора и загрузки файлов через форму на сайте. Для большого аудиоархива позже можно подключить отдельное объектное хранилище. Не загружайте в репозиторий конфиденциальные или неопубликованные материалы.
