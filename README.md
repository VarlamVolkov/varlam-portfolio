# Сайт-портфолио Варлама Волкова

Публичный статический сайт на GitHub Pages. Главная страница опубликована по адресу <https://varlamvolkov.github.io/varlam-portfolio/>.

## Страницы и каталог материалов

- `index.html` — главная
- `voice.html` — дикторское портфолио и каталог аудио
- `media.html` — сюжеты и видеоматериалы
- `science.html` — исследования и публикации
- `about.html` — обо мне
- `portfolio-data.json` — единый каталог событий, проектов, публикаций, выступлений, аудио, видео, исследований и профилей
- `assets/` — стили, скрипт, изображения и MP3

## Как самостоятельно обновлять сайт

Откройте репозиторий на GitHub и нажмите **Add file → Upload files**. Загрузите новый файл в нужную папку, затем добавьте одну запись в `portfolio-data.json`. Общий каталог автоматически распределяет её по нужным страницам. Подробная пошаговая инструкция находится в [`HOW_TO_UPDATE.md`](HOW_TO_UPDATE.md).

Новые записи появляются на сайте автоматически после сохранения каталога. Проверяйте, что имя загруженного файла и путь в JSON совпадают. События показываются от новых к ранним; изменения обычно становятся видны через несколько минут.

## Публикация

В **Settings → Pages** выбраны **Deploy from a branch**, ветка `main` и папка `/(root)`.
