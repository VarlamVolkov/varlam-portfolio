# Сайт-портфолио Варлама Волкова

Публичный статический сайт на GitHub Pages. Главная страница опубликована по адресу <https://varlamvolkov.github.io/varlam-portfolio/>.

## Страницы и каталоги

- `index.html` — главная
- `voice.html` — дикторское портфолио и каталог аудио
- `media.html` — сюжеты и видеоматериалы
- `science.html` — исследования и публикации
- `about.html` — обо мне
- `audio-library.json` — список аудиозаписей
- `video-library.json` — список видеосюжетов и внешних ссылок
- `assets/` — стили, скрипт, изображения и MP3

## Как самостоятельно обновлять сайт

Откройте репозиторий на GitHub и нажмите **Add file → Upload files**. Загрузите новый файл в нужную папку, затем отредактируйте соответствующий JSON-каталог через **Add file → Create new file** или кнопку редактирования. Подробная пошаговая инструкция находится в [`HOW_TO_UPDATE.md`](HOW_TO_UPDATE.md).

Новые записи появляются на сайте автоматически после сохранения каталога. Проверяйте, что имя загруженного файла и путь в JSON совпадают. Изменения обычно становятся видны через несколько минут.

## Публикация

В **Settings → Pages** выбраны **Deploy from a branch**, ветка `main` и папка `/(root)`.
