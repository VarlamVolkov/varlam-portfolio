# Портфолио Варлама Волкова

Одностраничный сайт на GitHub Pages: <https://varlamvolkov.github.io/varlam-portfolio/>. Все основные разделы находятся на главной и доступны через меню-якоря. Старые тематические страницы оставлены как архивные адреса.

## Где обновлять сайт

- `index.html` — структура, тексты и порядок разделов главной страницы.
- `portfolio-data.json` — общий каталог аудио, публикаций, проектов, выступлений, наград, волонтёрства и ссылок на профили. Материалы автоматически попадают в нужные блоки главной по значениям `category`.
- `assets/` — изображения, аудио, видео, стили и скрипт отображения.

Подробная инструкция — в [`HOW_TO_UPDATE.md`](HOW_TO_UPDATE.md).

## Публикация

В **Settings → Pages** выбраны **Deploy from a branch**, ветка `main` и папка `/(root)`. После отправки изменений в `main` GitHub Pages обычно обновляется через несколько минут.
